# Archive — four-direction exploration

**Historical. Not current guidance. Do not use for implementation.**

This folder preserves the process that led to Quiet:

- [`index.html`](index.html) — the interactive explorer with four complete directions (Quiet, Nocturne, Folio, Calibre).
- [`compare.html`](compare.html) — the four-up decision sheet.
- [`STYLE-OPTIONS.md`](STYLE-OPTIONS.md) — the written proposal and the decision.
- `assets/` — the explorer implementation.
- `screens/` — the four direction captures and the comparison sheet.

Quiet was chosen on 24 October 2026. The system that followed is in [`../../design-system/`](../../design-system/). The other directions are retained for rationale only: they are not alternative themes, and agents must not import them.

The explorer is plain HTML/CSS/JS so the comparison could be immediate. It is not a component library and does not imply the delivery stack.
